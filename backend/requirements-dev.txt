# Dependency auditing. Specifically pip-audit rather than osv-scanner: run
# against a requirements file of `>=` floors, osv-scanner resolves each

# against aiohttp 3.9.5 when the resolved environment has 3.13.3. pip-audit
# performs a real resolution, which gave 0 for the Vercel deploy surface.
#   pip-audit -r requirements.txt          # what the deployment resolves to
#   pip-audit                              # what is installed right now
